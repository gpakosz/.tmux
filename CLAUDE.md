## Overview

This is a fork of [gpakosz/.tmux](https://github.com/gpakosz/.tmux) ("oh-my-tmux") — a self-contained tmux configuration. It consists of two config files and a Makefile for deployment.

## Upstream Baseline

Both config files were last synced to upstream `gpakosz/.tmux@master` on **2026-06-23**. Upstream requires **tmux >= 2.6** (older versions are no longer supported). `.tmux.conf` is byte-identical to upstream; `.tmux.conf.local` is upstream's template with the local deviations re-applied (see below).

## Key Architecture Rule

**Never edit `.tmux.conf`** — it is the upstream base config and is explicitly marked "do not edit this file." All customizations belong exclusively in `.tmux.conf.local`. (The 2026-06-23 upstream sync was a one-time exception, not a standing policy.)

## Files

- `.tmux.conf` — upstream base config; read-only from a customization standpoint
- `.tmux.conf.local` — all user overrides, theme settings, and TPM plugin declarations
- `extra.sh` — installs fzf-tmux utilities to `~/.bin/`
- `Makefile` — deployment helpers

## Makefile Targets

```bash
make backup          # tar backup of both config files
make place-configs   # clone repo, create ~/.tmux.conf symlink, copy .tmux.conf.local to ~
make extra-tmux      # install fzf-tmux and fzf-panes scripts to ~/.bin/
make reload          # tmux source-file ~/.tmux.conf (live-reload running tmux)
```

## TPM Plugin Configuration

Plugins are declared in `.tmux.conf.local` with `set -g @plugin`. Currently active:
- `tmux-plugins/tmux-resurrect` — session persistence, pane content capture on
- `tmux-plugins/tmux-prefix-highlight` — prefix indicator in status bar
- `tmux-plugins/tmux-continuum` — auto-restore on launch
- `sainnhe/tmux-fzf` — fzf integration

**Do not** add `set -g @plugin 'tmux-plugins/tpm'` or `run '~/.tmux/plugins/tpm/tpm'` — TPM bootstrapping is handled automatically by the base `.tmux.conf`.

The `tmux-prefix-highlight` indicator is surfaced by the `#{prefix_highlight}` token appended to `tmux_conf_theme_status_right` (a local addition not present in the upstream template).

## Local Deviations from the Upstream Template

`.tmux.conf.local` differs from upstream's stock template only by these edits:
- `tmux_conf_copy_to_os_clipboard=true` (template default is `false`)
- `tmux_conf_new_pane_retain_current_path=true` (now matches the template default)
- `if-shell`-guarded `reattach-to-user-namespace` block (macOS-only; a no-op on Linux)
- `set -g history-limit 20000`
- `set -g mouse on`
- the 4-plugin TPM block + `@resurrect-capture-pane-contents`/`@continuum-restore`
- `#{prefix_highlight}` appended to `tmux_conf_theme_status_right`

## New Template Options (since the sync)

The refreshed template surfaces these options; all are left at upstream defaults unless changed:
`tmux_conf_theme` (master theme toggle), `tmux_conf_preserve_stock_bindings`, `tmux_conf_new_session_retain_current_path`, `tmux_conf_new_window_reconnect_ssh`, `tmux_conf_uninstall_plugins_on_reload`, `tmux_conf_urlscan_options`.

## Custom Status-Line Variables

To define a custom `#{foo}` variable for use in `tmux_conf_theme_status_left/right`, add a POSIX shell function in `.tmux.conf.local` between the `# EOF` and `# "$@"` sentinel lines at the bottom of the file. The opening brace `{` must be on the same line as the function name.

## Installation (from scratch)

```bash
git clone git@github.com:bossjones/.tmux.git ~/dev/bossjones/oh-my-tmux
ln -s -f ~/dev/bossjones/oh-my-tmux/.tmux.conf ~/.tmux.conf
cp ~/dev/bossjones/oh-my-tmux/.tmux.conf.local ~/.tmux.conf.local
```

After editing `~/.tmux.conf.local`, reload with `<prefix> r` or `make reload`.
